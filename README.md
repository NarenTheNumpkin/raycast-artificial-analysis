# Artificial Analysis for Raycast

A macOS Raycast extension for browsing AI models ranked by the Artificial Analysis Intelligence Index.

Requires Node.js 22.22.2 or later, npm, Raycast, and a free [Artificial Analysis API key](https://artificialanalysis.ai/api-key-management-redirect).

```sh
npm install
npm run dev
```

Data provided by [Artificial Analysis](https://artificialanalysis.ai/).
